# 🐾 PetJunior — Site Institucional

## 📌 Sobre o projeto

O PetJunior é um site institucional de um pet shop, desenvolvido como projeto acadêmico com o objetivo de praticar os fundamentos do desenvolvimento web.

O site apresenta informações sobre o estabelecimento, galeria de imagens, localização e formulário de contato.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3

## ▶️ Como executar

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` em um navegador.
